# Diwali Shop Ledger

Static page (`index.html`) + Supabase (logins and database). Hosted on GitHub Pages.

- Users: ajay, mahesh, babu, shiva, anil, sashi (accounts `<name>@diwali-shop.app` in Supabase Auth). Public sign-up is disabled.
- Data: table `entries` in the Supabase project `diwali-shop-ledger`; only logged-in partners can read or write.
- Passwords are not stored in this repo. Change one in the Supabase dashboard → Authentication → Users.
- The key in `index.html` is the public "anon" key – safe by design.

Add to phone: open the link → Chrome ⋮ → *Add to Home screen* (Android) / Safari Share → *Add to Home Screen* (iPhone).
